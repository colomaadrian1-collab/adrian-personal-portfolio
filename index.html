Library Shelf Capacity Analyzer

This project is developed using Java. It uses a one-dimensional array to store the number of books on 12 library shelves. It calculates the total number of books, counts shelves that are at least 90% occupied, and identifies the shelf with the most available space.

Source Code

import java.util.Scanner;

public class LibraryShelf {

    public static void main(String[] args) {

        Scanner input = new Scanner(System.in);

        int[] books = new int[12];

        int total = 0;
        int occupied = 0;
        int mostSpace = 0;

        // Input books for 12 shelves
        for (int i = 0; i < 12; i++) {

            System.out.print(
                "Enter books for shelf index " + i + ": "
            );

            books[i] = input.nextInt();

            // Validate input
            while (books[i] < 0 || books[i] > 100) {

                System.out.print(
                    "Invalid input! Enter 0-100: "
                );

                books[i] = input.nextInt();
            }

            // Calculate total books
            total = total + books[i];

            // Count shelves at least 90% occupied
            if (books[i] >= 90) {
                occupied++;
            }

            // Find shelf with most available space
            if (books[i] < books[mostSpace]) {
                mostSpace = i;
            }
        }

        // Display results
        System.out.println("\n===== SHELF ANALYSIS =====");

        System.out.println(
            "Total number of books: " + total
        );

        System.out.println(
            "Shelves at least 90% occupied: " + occupied
        );

        System.out.println(
            "Shelf with most available space (index): "
            + mostSpace
        );

        System.out.println(
            "Available space: "
            + (100 - books[mostSpace]) + " books"
        );

        input.close();
    }
}

Program Explanation

The program uses a one-dimensional array to store the number of books on 12 shelves. Scanner accepts user input, while loops validate the values from 0 to 100. Conditional statements calculate the total books, count shelves that are at least 90% occupied, and identify the shelf with the most available space.
